## 🔌 نقاط الـ API
| المسار | الطريقة | الوصف | المدخلات |
|--------|---------|-------|----------|
| `/` | GET | صفحة الحاسبة الرئيسية | - |
| `/api/health` | GET | فحص صحة الخدمة | - |
| `/api/calculate` | POST | عملية ثنائية | `{ a, b, op }` حيث op: `+ - * / % ^` |
| `/api/scientific` | POST | دالة على رقم واحد | `{ value, fn }` حيث fn: `sqrt / square / inverse / percent` |

**مثال:**
```bash
curl -X POST http://localhost:3000/api/calculate \
  -H "Content-Type: application/json" \
  -d '{"a": 15, "b": 3, "op": "/"}'
# => {"success":true,"a":15,"b":3,"op":"/","result":5}
```

## 🖥️ طريقة التشغيل محلياً
```bash
# 1. تثبيت الاعتمادات (مثبتة مسبقاً في الـ sandbox)
cd /home/user/webapp && npm install

# 2. البناء
npm run build

# 3. التشغيل عبر PM2
fuser -k 3000/tcp 2>/dev/null || true
pm2 start ecosystem.config.cjs

# 4. الاختبار
curl http://localhost:3000/api/health

# فحص السجلات
pm2 logs webapp --nostream
```

## 📖 دليل الاستخدام
1. افتح الرابط في المتصفح
2. استخدم الأزرار أو لوحة المفاتيح لإدخال الأرقام والعمليات
3. اضغط `=` أو `Enter` للحصول على النتيجة
4. راجع سجل العمليات في اللوحة الجانبية — انقر أي عملية لاسترجاع نتيجتها
5. `Esc` للمسح الكامل، `Backspace` لحذف رقم

## 💾 بنية البيانات والتخزين
- **سجل العمليات**: مخزن في `localStorage` بالمتصفح (آخر 50 عملية)
  - البنية: `{ expr: string, result: string, time: string }[]`
- **تدفق البيانات**: المتصفح → POST إلى Hono API → حساب على الخادم → النتيجة تعرض وتحفظ في السجل محلياً
- **لا حاجة لقاعدة بيانات حالياً** — عند إضافة الحسابات مستقبلاً سيُستخدم Cloudflare D1
